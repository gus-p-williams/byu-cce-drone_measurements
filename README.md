# byu-cce-drone_measurements — ARCHIVED

**This repository has moved. Work continues at
[byu-cce-drones/content](https://github.com/byu-cce-drones/content).**

This was an earlier source repository for the BYU CCE freshman drone measurement class. It is kept
for history only. It is not built, not published, and not maintained.

- **Live site:** <https://byu-cce-aerial-measurements.readthedocs.io>
- **Current source:** <https://github.com/byu-cce-drones/content>

## What happened

The course was being written in two unrelated repositories at the same time. This one held the
rewritten reading pages, the generated figures and the `fig_tools/` toolkit; the organization
repository held the labs, the syllabus and the TA material, and was the one actually publishing the
site.

On 2026-09-04 everything here was ported into `byu-cce-drones/content` and merged, page by page,
keeping whichever version was newer on each side. Nothing was lost. That repository now holds the
readings, the labs, the syllabus, the Part 107 material, the final project and the figure toolkit
together, and it is the only one that publishes.

Please do not commit here. Anything added to this repository will not reach students.
